I created a public workflow for **SMRF**, short for **Statistical-genomics Mixed Random Forest**.

SMRF is a machine-learning framework for analyzing genome-wide marker data while accounting for genetic relatedness among individuals. The method first adjusts the phenotype using an intercept-only linear mixed model and then trains a random forest on the adjusted trait values using genome-wide SNP markers as predictors.

The workflow includes input preparation, mixed-model adjustment, random forest fitting, marker-level feature importance, optional residual permutation testing, and Genome-Wide Feature Importance visualization.
